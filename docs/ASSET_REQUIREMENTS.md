# Вимоги до матеріалів

| Тип | Формат і розміри | Метадані |
| --- | --- | --- |
| Персонаж | PNG RGBA, комірка 128×192; окремий лист для кожного clip; 4 рядки south, west, east, north; ширина = кадри × 128, висота 768 | `frame`, `directions`, `clips`, `worldHeight`, `defaultSocketsPx` |
| Малий предмет | PNG RGBA `world.png`, `icon.png` по 128×128 | `frame`, `worldSize`, `files` |
| Великий реквізит | PNG RGBA; поточний fallback використовує 128×128, фінальний арт може мати інший розмір після зміни `frame` | `worldSize`, `frame` |
| Площина середовища | PNG RGBA; рекомендовано 512×512 для плитки, до 2048 px для великих декорацій | `renderMode`, `worldSize`, repeat/side при додаванні підтримки |
| UI і карта | SVG або PNG; карта близько 512×768, портрет 256×256 | окремий текст українською, не запечений у картинку |
| Звук | WAV 48 kHz для джерела; локальний OGG/WAV/MP3 для runtime | eventId, category, gain, loop, spatial при додаванні файлового аудіо |

Контракт персонажа: `idle` 4 кадри × 4 fps, `walk` 6×8, `talk` 4×6, `interact` 6×8, `react` 4×8, `perform` 8×8. Необов’язковий `carry_walk` має fallback на `walk`. Порядок напрямків незмінний: south, west, east, north. Для 6 кадрів розмір листа 768×768. Прозорий край у кожній комірці — щонайменше 2 px; фон і тінь кімнати не малюються всередині спрайта. Рекомендований `anchorPx`: `[64,176]`; `handRight [94,112]`, `handLeft [34,112]`, `head [64,38]` у координатах комірки від верхнього лівого кута. Усі кадри одного пакета мають однаковий canvas та anchor. Колір — sRGB.

У поточному коді loader читає `frameCount`, порядок напрямків і файл clip. `worldHeight`, sockets, нестандартні розміри предметів та шари екіпіровки описані в метаданих, але їхнє повне відображення ще обмежене; див. [KNOWN_LIMITATIONS](KNOWN_LIMITATIONS.md). До художньої здачі перевіряйте `npm run assets:validate -- --require-final` та сцену preview.

Шрифт для фінального UI має містити І, Ї, Є, Ґ та український апостроф; нині використано системний Georgia/Arial fallback. Декоративні посилання й зовнішні файли у runtime не потрібні.
