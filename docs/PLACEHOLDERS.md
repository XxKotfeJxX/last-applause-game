# Процедурні заглушки

`src/render/assets.ts` малює через Canvas 4 напрямки базових clips для кожного персонажа. `idle` дихає, `walk` міняє кроки, `talk` жестикулює, `interact` тягнеться рукою, `react` показує реакцію, `perform` додає сценічний рух. Окремі UV кожного mesh читають актуальний кадр із `animationStartedAt` і `gameTimeMs`. Гравець має ту саму систему, великі предмети показуються поряд із носієм. `src/render/scene.ts` створює підлоги, стіни, колесо, меблі та галерею простими 3D-примітивами.

`src/audio/audio.ts` синтезує місцеві звуки через Web Audio: UI, номер, ніж, розпад, перемогу й смерть. Музичні голоси зникають зі стадіями цирку. Файлів стороннього аудіо немає. Кольори персонажів задаються в `content/characters/characters.json`, форми предметів — у `src/render/assets.ts`.

У `public/assets/` створено 14 пакетів метаданих із 56 оголошеними, але поки відсутніми PNG. Вони є точними слотами для художника; `npm run assets:validate` друкує список. Заміна кадру не змінює стан NPC або хід часу. Для фінального арту потрібні всі шість clips героя й шести NPC, а також `world.png`/`icon.png` семи предметів, карта, фонова фактура, шрифт і звукові файли після окремого погодження стилю. Поточна гра повністю локальна й працює без них.
