# Відомі обмеження

- P1 (падіння, резервуар, темна кінцівка) і P2 (класи, інші камери, кооператив) вимкнені. Активний сценарій тільки `scenario.wheel`.
- Художніх PNG, файлового аудіо та окремого українського шрифту немає. 56 слотів використовують процедурні заглушки; застосунок має стандартну іконку Electron.
- Візуал галереї та коридорів схематичний; колізія задається прямокутниками. Немає окремої механіки дверей для гравця, ухилення NPC одне від одного й повного occlusion culling.
- Діалоги зберігаються як умовні рядки з пріоритетом; великий граф вузлів і універсальний реєстр JSON-ефектів не реалізовані. Більшість UI-тексту ще в TypeScript, а не в окремому locale-файлі. Новий тип дії потребує коду та тестів.
- Метадані пакетів уже містять sockets, але відображення екіпіровки поверх PNG, нестандартних розмірів персонажа, складних середовищних карт і файлового аудіо ще не завершене. Заміна стандартного `walk.png` 128×192 працює; для іншого формату потрібна перевірка в сцені після зміни метаданих.
- Збереження версії 1 повні, але міграцій старих ID поки немає. Зміна ID без міграції відхиляє старий файл з поясненням.
- Автоматичні тести проходять цикл і веб UI; ручний плейтест на чужому Windows ноутбуці, реальна тривалість 10–20 хвилин, продуктивність на слабкому GPU й інші ОС не виміряні.
- Windows portable створено без власного підпису видавця. Перевіряйте репутаційні попередження Windows на машині демонстрації.
