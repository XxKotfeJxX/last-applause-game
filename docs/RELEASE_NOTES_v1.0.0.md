# Останні оплески 1.0.0

Перший ігровий прототип для Windows x64. Завантажте `last-applause-1.0.0-windows-x64.exe` нижче й запустіть його без встановлення Node.js або окремого інсталятора.

- Сім зон цирку, шість персонажів, пошук предметів і перестановка трьох номерів.
- Фінал із колесом і двома шляхами порятунку; локальне збереження та контрольна точка.
- Перевірено 17 логічними й 3 браузерними тестами. Готовий portable-файл пройшов локальну перевірку запуску, WebGL-сцени та збереження.

Графіка й анімація персонажів поки процедурні. Повний ручний плейтест на іншому комп’ютері та вимірювання FPS ще не проведено. Докладніше: [звіт перевірок](https://github.com/XxKotfeJxX/last-applause-game/blob/main/docs/TEST_REPORT.md) і [відомі обмеження](https://github.com/XxKotfeJxX/last-applause-game/blob/main/docs/KNOWN_LIMITATIONS.md).
