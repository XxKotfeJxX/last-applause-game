# Звіт перевірок

## 1.4.0: точна плавна прозорість, анімешні риги й таро — 01.11.2026

`npm run check`: 48/48 unit/integration, content/assets validation (0 помилок/відсутніх активних слотів), TypeScript і lint пройшли. `build:desktop` пройшов. Сім стилізованих ригів використовують 21–54 меші, статичні поверхні об’єднані в межах суглобів. Геометричні тести прозорості охоплюють порожні отвори, бічний контакт, незалежність матеріалів, поступову зміну opacity й повернення батчів. Нові тести не оцінюють суб’єктивну художню якість.

Браузер: майстерня таро переглянута на 1363×936, усі шість ілюстрацій завантажилися, підписи читабельні; натискання відкриває збільшення й зберігає фокус. Пророцтво у грі використовує той самий компонент. Повний WebGL/UI/E2E прогін сцени, нові персонажі на GPU й FPS не підтверджені через вимкнений WebGL у cloud Chrome. Windows portable 1.4 не пакувався/не запускався. Деталі: [VISUALS_1_4](VISUALS_1_4.md), [TAROT_ART_PROMPTS](TAROT_ART_PROMPTS.md).

## 1.2.1: усунення накладених поверхонь — 01.11.2026

Знайдено й виправлено копланарні грані різних матеріалів у стелажах, скринях, ящиках, арках, порталах, шторі й рамці портрета. Перекладини більше не накладаються на стійки; обручі скринь виступають над кришками. Прибрано дубльовані спиці шестерень.

Кімнати мають одну видиму поверхню підлоги: верхню грань фундаментного блока видалено. Перехід малюється лише між краями кімнат, а шви настилу повторюють нахил поверхні. Колізії й висота ходьби не змінені.

`npm run check`: 35/35 тестів, типи, lint і валідації пройшли. Нові регресії перевіряють перетин співнапрямлених копланарних BoxGeometry-граней різних матеріалів у всіх 55 розміщеннях, відсутність настилу поверх кімнатної підлоги, відсутність верхньої грані фундаменту та висоту швів на пандусах. Перевірка граней спочатку відтворила проблему на попередній геометрії. `npm run build:desktop` пройшов. Візуальний GPU-прогін залишається неперевіреним через раніше зафіксований вимкнений WebGL у cloud Chrome.
