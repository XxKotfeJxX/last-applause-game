# Звіт перевірок

## Оновлення локацій і ТЗ 1.1 — 31.10.2026

Поточні зміни перевірено в Linux-середовищі, Node.js 24.22.1, npm 11.9.0, Playwright Chromium 140.0.7339.16, 1280×720. Windows-перевірки нижче стосуються попереднього релізу 1.0.0 й не є перевіркою нової настільної збірки.

| Перевірка | Поточний результат |
| --- | --- |
| `npm run check` | Пройшло: контент, асети, TypeScript, ESLint і 17 тестів. |
| `npm run assets:validate` | 0 помилок; 56 початкових слотів персонажів/предметів залишаються на заглушках. Сім нових зображень оточення наявні. |
| `npm run build:desktop` | Пройшло: вебзбірка та компіляція Electron main. Це не запуск Windows portable. |
| `npm run test:e2e` | 4/4 пройшли за приблизно 1,5 хв: сім локацій і WebP; ввід/огляд/save-load; UI-перестановка й виступ; фінал із двійником. Необроблених помилок і провалених запитів зображень не виявлено. |
| Проходження й автономність | Наявні 17 тестів охоплюють шість порядків номерів, два способи вижити, власність предметів і задачі NPC. Логіка цих систем не змінювалася. |
| Збереження й геометричні прив’язки | `world.json`, domain, navigation і `main.ts` не змінено. Координати та формат save сумісні з поточним 1.0.0. |
| Візуальний огляд | Переглянуто кадри семи зон і фінальну постановку; приклади нижче. |
| Windows portable з новим артом | Не зібрано й не запущено в поточному Linux-середовищі. Опублікований exe 1.0.0 автоматично не оновлюється після зміни джерел. |

Наскрізний UI-тест із фактичним очікуванням руху артиста під програмним WebGL зайняв 46,7 секунди; його бюджет збільшено до 90 секунд без зміни перевірок чи прискорення NPC. Перший прогін з попереднім 30-секундним бюджетом завершився timeout саме очікуванням артиста. Повторний повний прогін пройшов. FPS на цільовому ноутбуці не вимірювалися.

## Попередній звіт релізу 1.0.0

Нижче збережено попередній звіт із репозиторію; це результати попереднього виконавця для тієї збірки.

Середовище: Windows 11 Home x64, build 10.0.26200; Node.js 20.19.5; npm 11.6.3; Chrome 141.0.7390.67; Electron 38.1.2. Браузерні перевірки виконувалися на 1280×720. GPU та середній FPS не виміряні, тому ціль 60 FPS не заявлена як підтверджена.

| Команда / перевірка | Фактичний результат |
| --- | --- |
| `npm run content:validate` | 6 NPC, 7 предметів, 3 номери, 7 зон, 10 рядків діалогів; помилок немає. |
| `npm run assets:validate` | 0 помилок, 56 слотів фінальних PNG відсутні й мають процедурний fallback. |
| `npm run typecheck` і `npm run lint` | Пройшли. |
| `npm test` | 17 тестів пройшли: автономне підбирання ножів, скасування подій, єдина власність, закрита брама, перестановки, шість порядків, обидва порятунки й причина смерті. |
| `npm run test:e2e` | 3 браузерні тести пройшли: WebGL-сцена, ввід, огляд, меню, save/load; реальна UI-перестановка й повернення до дослідження після номера; фінальна сцена з одягненим двійником. Необроблених помилок сторінки не було. |
| `npm run assets:proof` | Тимчасовий `stagehand/walk.png` 768×768 підключився до Гната з HTTP 200; інші NPC не запитували PNG. Файл видалено, каталог відновлено. |
| `npm run build:web`, `npm run build:desktop` | Пройшли; вебзбірка в `dist-web/`, Electron main в `dist-electron/`. Vite попереджає про JS chunk близько 566 kB до стиснення. |
| `npm run pack:win` | Пройшло на Windows x64; `release/Останні оплески 1.0.0.exe` має 82 091 174 байтів. |
| `node tools/desktop-smoke.mjs` | Фінальний запакований `win-unpacked` відкрив `app://game/index.html`, WebGL canvas і записав локальне збереження. |
| `node tools/portable-smoke.mjs` | Фінальний portable `.exe` запущено без dev-сервера; CDP побачив `app://game/index.html`, WebGL canvas, локальне збереження й 0 помилок сторінки. |

Ручний огляд стартового кадру й фінальної постановки виконано; скриншоти у [preview.png](preview.png) та [preview-finale.png](preview-finale.png). Повний ручний 10–20-хвилинний плейтест із різними гравцями, замір FPS, зовнішня машина Windows, macOS і Linux залишаються неперевіреними. `--require-final` навмисно не проходить, доки не додано фінальні PNG.
