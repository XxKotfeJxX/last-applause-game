# Формат збереження

Ключі `last-applause:v1:manual` і `last-applause:v1:checkpoint` зберігаються в `localStorage` стабільного origin: адреси Vite для вебверсії або `app://game` для Electron. Запис `setItem` одного ключа атомарний: невдалий запис не замінює старий валідний. Ручне збереження доступне в паузі поза номером. Авточекпойнт ставиться до підготовчого номера, після його завершення, після останньої перевірки та до фінального сигналу.

`WorldState` має `schemaVersion: 1`, `contentPackId`, `contentVersion`, `seed`, `gameTimeMs`, гравця, акторів із маршрутами й revision, предмети з єдиною location, факти, механізми, слоти, угоди, стани зон, стадію розпаду, чергу подій, журнал, активний номер та результат. Ніяких DOM, Three.js, таймерів або функцій у JSON немає.

`loadWorld` перевіряє версію схеми й пакета та відхиляє несумісне збереження з повідомленням. Міграція ID наразі не реалізована: для змін ID потрібен окремий крок міграції перед збільшенням `contentVersion`. Заміна тільки PNG/метаданих візуалу не змінює цей номер і не скидає прогрес. Після смерті retry завантажує весь checkpoint, включно з NPC, власністю речей і програмою.
