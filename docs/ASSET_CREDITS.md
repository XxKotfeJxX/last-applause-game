# Авторство матеріалів

Поточні 3D-примітиви, CanvasTexture заглушки, оформлення інтерфейсу та синтезовані звуки створені кодом саме для цього проєкту. Зовнішні моделі, набори персонажів, музика, ілюстрації та шрифти не використані. У майбутньому перед додаванням фінального файлу запишіть тут автора, джерело, ліцензію й точний слот пакета.
