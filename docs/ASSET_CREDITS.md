# Авторство матеріалів

3D-примітиви, CanvasTexture заглушки персонажів/предметів, оформлення інтерфейсу та синтезовані звуки створені кодом саме для цього проєкту. Готові сторонні моделі, набори персонажів, музика й шрифти не використані.

31.10.2026 для семи локацій створено оригінальні зображення через вбудований image_gen: `public/assets/environment/{arena,foyer,backstage,dressing,props,understage,gallery}/floor.webp`. Це згенероване для проєкту оформлення, не сторонній набір асетів. Файли оптимізовані у WebP без зміни композиції. Палітра, призначення та повний набір промптів — у [ENVIRONMENT_ART.md](ENVIRONMENT_ART.md).

Нові арки, оздоблення, ліхтарі, дзеркала, полиці, труби й механізми створені кодом із примітивів. Джерела й умови використання майбутніх сторонніх матеріалів слід додавати окремо.

Додаткові 3 матеріали стін і 5 стаціонарних об’єктів також створені вбудованим image_gen 31.10.2026. Пакети, призначення й точні промпти: [WALLS_AND_FIXTURES](WALLS_AND_FIXTURES.md).
