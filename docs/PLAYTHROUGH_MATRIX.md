# Матриця проходжень P0

Інтеграційний тест `tests/integration/playthrough.test.ts` проходить ці порядки через ті самі команди `movePlayer`, `execute` й `tickWorld`, що використовує гра. Перед переговорами гравець налаштовує шафу, лебідку й колесо; потрібні умови всіх кандидатів тоді вже виконані. Поточний артист дає згоду, конферансьє міняє слоти. Кожен номер запускається лише після виходу артиста на манеж і двох сигналів.

| Порядок | Перестановки від початкового | Фінал у тесті |
| --- | --- | --- |
| Шафа → Повітря → Ножі | немає | сценічні ножі, фарба, маска |
| Шафа → Ножі → Повітря | Марко перед Ладою | той самий |
| Повітря → Шафа → Ножі | Лада перед Северином | той самий |
| Повітря → Ножі → Шафа | Лада перед Северином; Марко перед Северином | той самий |
| Ножі → Шафа → Повітря | Марко перед Северином | той самий |
| Ножі → Повітря → Шафа | Марко перед Северином; Лада перед Северином | той самий |

Друга повна інтеграційна сесія бере костюм, маску й великого двійника, завершує три номери, встановлює двійника після перевірки, готує затемнення й прохід та виживає за завісою. Третя сесія навмисно запускає непідготовлений фінал і перевіряє конкретну причину смерті. Тести виконуються `npm test`.

Для ручної перевірки без dev-меню: почніть гру; зберіть маску в гримерці; підготуйте три станції; попросіть потрібного майбутнього артиста, поточного та конферансьє про перестановку; після всіх номерів попросіть останню перевірку; виконайте один із двох маршрутів із [GAMEPLAY](GAMEPLAY.md); перевірте retry з checkpoint після неповної постановки. Відкладений художній плейтест має оцінити читабельність усіх ракурсів і реальну тривалість.
