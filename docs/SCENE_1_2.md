# Геометрія, реквізит та інвентар 1.2.0

Запит користувача від 01.11.2026 розширює початковий план: весь реквізит і предмети тепер мають геометрію 3D; персонажі зберігають попередні анімовані billboard-спрайти. Готові сторонні моделі не завантажувалися. Моделі оригінальні, створені у Three.js із власних форм і примітивів; мальовані підлоги та матеріали стін збережені.

## Що на мапі

55 розміщень описані в `content/areas/objects.json`. `src/render/models.ts` будує для кожного виду впізнавану складену модель.

| Елементи | Деталі |
| --- | --- |
| Шафа | Дверні панелі, карниз, стійки, ніжки, ручки, золота зірка |
| Верстак | Стільниця, шухляди, нижня полиця, ніжки, закріплені лещата |
| Колесо | Опори, кругла дерев’яна мішень, кольорові сектори, обід і ремені; окремий обертовий вузол |
| Лебідка | Рама, два барабани, витки троса, зубчасте колесо й важіль |
| Брама | Стовпи, прути й стулка, що повертається при відкриванні |
| Афіші | Рамки, опори, поверхня з текстом; програма показує чинний порядок і статус номерів |
| Люк / сценічна мітка | Плаский настил із ручкою; кільце й зірка врівень із підлогою |
| Меблі | Лави, оббиті скрині, ящики з планками, наповнені стелажі, гримерні столи із дзеркалами |

Старі cutout зображення стаціонарних об’єктів збережені як художні референси; поточна сцена будує ці об’єкти геометрією. Вони не є другою невидимою стіною.

## Предмети та інвентар

Усі сім предметів мають моделі: маска з отворами для очей, дерев’яний сценічний манекен, костюм, два різні комплекти ножів, флакон фарби й гайковий ключ. Сценічні ножі відрізняються зеленими округленими кінцями/акцентами; бойові мають гостру форму й червоний акцент.

`ItemDef.modelId` обирає рецепт у ModelFactory. Метадані `public/assets/items/<slug>/asset.meta.json` мають `renderMode: proceduralModel`, `modelId` і `worldSize`. Рецепт нормалізується до заявленої висоти з опорою на y=0. Під час підбирання переміщується чинний екземпляр; модель не створює копій логічного предмета.

`src/render/item-icons.ts` рендерить **той самий** ModelFactory.item у прозорий PNG 192×192 через окрему ортографічну камеру. Результат кешується за visualId/modelId. Ці зображення показані на кнопках інвентарю та в огляді предмета. Корпус персонажа не перероблено; маска й ноша прив’язані до sockets. Встановлені двійник, костюм і маска використовують координати обертового вузла колеса.

## Єдина геометрія руху

- `src/world/layout.ts` виводить сегменти стін із плану кімнат та їхніх проходів. Той самий масив споживають renderer і collision.
- Висота підлоги береться з `AreaDef.floorY`. Для переходу обчислюються краї двох кімнат та інтерполяція між ними. Обидва пандуси мають пласкі посадкові ділянки; їхня верхня сітка побудована саме за surfaceHeight, без окремого горизонтального блока над головою.
- `collisionBodies` враховує стіни, меблі, стовпи арок, брами й відкриту стулку. Перевірка має висоту: під піднятими трубами та арками є прохід. Люк і сценічна мітка не блокують рух.
- Герой і NPC використовують moveOnFloor із тілом радіуса 0.22 м та перевіркою простору до 1.8 м. Рух поділений на відрізки до 0.07 м і ковзає вздовж вільної осі; висота кроку обмежена. Край настилу перевіряється по колу опори.
- Зникнення лав чи іншого реквізиту прибирає також їхню колізію. DEV-накладання показує саме collisionBodies, включно з повернутою стулкою.
- Після load repairWorldPositions виправляє старі координати всередині нових перешкод. Предмети, угоди й прогрес не скидаються.

Для вільного центрального маршруту переставлено шафу/верстак/лебідку, а програму розміщено біля стіни закулісся. Точки взаємодії та моделі перевіряються на збіг координат. NPC лишаються на авторських графових маршрутах; це не динамічний navmesh. Додавши меблі на маршрут, оновіть граф або розміщення: тест перевіряє прохідність кожного ребра.

## Як додавати й замінювати

1. Змініть розміщення, kind та габарити в `objects.json`. Стаціонарний механізм також має узгоджуватися зі своїм interactable у world.json.
2. Новий вид моделі додайте в `content/models/catalog.json` і ModelFactory.object / ModelFactory.item. Не реєструйте меблі як інвентарні предмети.
3. Новий звичайний предмет: `npm run new:item -- --id item.example`. За замовчуванням він має модель parcel та іконку з її геометрії. Виберіть інший modelId, capabilities, розміщення й worldSize.
4. Запустіть `npm run check` та `npm run build:desktop`. Перевірте мапу й інвентар на машині з WebGL2. Текстури не заміняють геометричний рецепт proceduralModel.

Колізії — об’ємні прямокутні оболонки, а не точні трикутники кожної ручки. Підлога має авторську висоту без стрибків, присідання чи rigid-body фізики. NPC поки можуть проходити одне крізь одного. Візуальна продуктивність на цільовому GPU не виміряна.
